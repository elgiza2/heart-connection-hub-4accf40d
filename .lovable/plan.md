# خطة: تحويل الوكيل إلى وكيل كامل (مستوى Manus)

الهدف: الوكيل ينفّذ **أي** مهمة داخل نفس الشات — برمجة، تكاملات، MCP، تشغيل كود، إنتاج ملفات، وتشغيل المتصفح عند الحاجة — يكمّلها لآخرها حتى لو أخذت ساعات، ويقول للمستخدم صراحة "دلوقتي بأراجع اللي عملته" ثم يراجع ويصلّح.

## ١. تصنيف المهمة قبل التنفيذ
- المخطِّط (`agent_plans`) يرجع الآن `kind`:
  - `browser` = المهمة كلها تشغيل واجهة موقع (تسجيل دخول، فورمات، كليك).
  - `agentic` = كل الباقي: برمجة، بيانات، ملفات، APIs، MCP، ومهام مختلطة.
- المهام المختلطة تبدأ `agentic`، والوكيل نفسه يسلّم جزء المتصفح لأداة `browser_task`.

## ٢. المُنفِّذ الوكيلي (ReAct server-side)
ملف جديد `_shared/agentkernel/executor.ts`: كل دورة يختار الموديل **أداة واحدة** بقرار منه، وتُسجَّل الملاحظة في `long_run_events`، فتكمل المهمة عبر عدة ticks بدون فقدان السياق.

الأدوات:
| الأداة | الاستخدام |
| --- | --- |
| `run_code` | تشغيل JavaScript/TypeScript حقيقي في Worker معزول (بدون صلاحيات) لتحليل البيانات، الحسابات، توليد الملفات |
| `mcp_call` / `list_mcp_tools` | التكاملات: نداء أدوات سيرفرات MCP المربوطة للمستخدم من `mcp_connections` عبر JSON-RPC |
| `write_file` / `read_file` | إنتاج وقراءة مخرجات (كود، تقارير، CSV) قابلة للتحميل |
| `web_search` | البحث عند الحاجة فقط، مش هدف المهمة |
| `browser_task` | تسليم جزء واجهة الموقع للمتصفح السحابي |
| `remember` | تخزين معرفة دائمة في `agent_memory` |
| `ask_user` | يوقف ويسأل: CAPTCHA، OTP، بيانات دخول، دفع، إجراء غير قابل للتراجع، هدف غامض |
| `finish` | الإنهاء فقط بعد التحقق الفعلي |

## ٣. المراجعة الذاتية المعلنة
- عند `finish` يتحوّل الـrun إلى مرحلة `reviewing` مع `status_text` معلن: "بأراجع اللي عملته" — يظهر في الشات فورًا.
- المراجع يقارن الهدف + معايير النجاح + كل الـtranscript + المخرجات، ويحكم: `pass` / `retry` / `ask`.
- `retry` يرجع لنفس اللوب بتوجيه تصحيحي (حتى ٣ جولات)، `ask` يوقف ويسأل، `pass` ينهي بملخّص + المخرجات.

## ٤. الاستمرارية والمهام الطويلة
- ميزانية افتراضية ٦ ساعات، حتى ٦٠٠ خطوة، checkpoints كل خطوة.
- كل tick محدود (عدد خطوات + مهلة زمنية) وبيقفل الـrun على نفسه (single-flight) عن طريق `last_heartbeat_at`، وبيكمل من نفس النقطة في الtick اللي بعده.
- كشف التكرار (fingerprint + strikes): يغيّر الطريقة، ولو فضل عالق يسأل المستخدم.
- إشعار عند الانتهاء أو عند الحاجة لتدخّل، وكل ده شغّال والتاب مقفول.

## ٥. الواجهة داخل نفس الشات
- بطاقة الوكيل تعرض: الخطة، كل خطوة/أداة مع ملاحظتها، جملة "بأراجع اللي عملته"، المخرجات القابلة للتحميل، وبطاقة السؤال للرد المباشر.

## ملاحظة تشغيلية مهمة
نشر Edge Functions حاليًا واقع من ناحية Supabase (`Internal error` لكل الدوال بما فيها القديمة غير المعدّلة). الكود جاهز ومُتحقق منه بـDeno، ولازم نعيد النشر لـ`long-run` (اللي دمجت جواه `cron_tick`) لما قناة النشر ترجع، وبعدها نحوّل الـcron من `agent-tick` إلى `long-run`.
